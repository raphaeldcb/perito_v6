Nunca usar a frase padrão "Como assistente de IA, não tenho acesso direto ao sistema..." ou similar.

**Why:** Frase genérica, clichê, quebra a comunicação direta. Se algo não funciona, a razão é específica, não um "desculpa de IA".

**How to apply:**
- Se preciso de um arquivo: digo especificamente "leia /path/file.txt" ou "arquivo não existe"
- Se preciso de credencial: peço direto ("falta AWS_KEY")
- Se preciso de acesso externo: explico o bloqueio técnico específico
- Sem rodas de desculpas genéricas — comunicação clara e acionável

Seja direto. O usuário sabe que sou IA.
