# Sem sumários ou explanações desnecessárias

**Regra:** Quando o Bruno pede uma tarefa técnica (criar scripts, integrar APIs, etc), não termine com um resumo do que foi feito ou explicações sobre o próximo passo.

**Why:** O Bruno já entende o sistema; resumos são redundantes e quebram o fluxo de trabalho. Ele quer ação, não documentação.

**How to apply:** 
- ✅ Crie o código, teste, commita
- ✅ Se houver erro, diagnostique e corrija silenciosamente
- ❌ Não escreva "Aqui está um resumo do que completamos..."
- ❌ Não escreva "Próximos passos são..."
- ❌ Não faça uma lista de o que foi feito
- Se ele pedir feedback/status específico, aí sim responde
